# SuperAero

Welcome to SuperAero, a premium aviation company website featuring stunning 3D animations and modern design.

## Features

- **3D Airplane Model**: Interactive Three.js powered airplane animation
- **Smooth Animations**: CSS and JavaScript powered animations throughout the site
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean, professional design with gradient backgrounds and hover effects

## Technologies Used

- HTML5
- CSS3 (with animations)
- JavaScript
- Three.js (for 3D graphics)

## Getting Started

1. Open `index.html` in your web browser
2. Enjoy the fully animated and 3D designed SuperAero website!
